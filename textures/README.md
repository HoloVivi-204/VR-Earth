# Textures Directory

Place your NASA texture files here. The app uses placeholder colors until real textures are added.

## Required Files

| File | Source | Resolution |
|------|--------|------------|
| `earth_color.jpg` | NASA Blue Marble (Visible Earth) | 8K–16K |
| `earth_night.jpg` | NASA Black Marble | 8K |
| `earth_displacement.jpg` | CGIAR-CSI SRTM 90m | 8K–16K |
| `moon_color.jpg` | LROC WAC Mosaic | 8K–16K |
| `moon_displacement.jpg` | NASA LRO LOLA | 8K |
